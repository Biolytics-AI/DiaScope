## What the walkthrough covers

1. How a clinician request enters the EHR flow and is stripped of PHI.
2. How HealthcareProvider-side key management and RBAC gate access before traffic leaves the controller boundary.
3. Which processor-side contractual and residency controls must exist before onboarding a GPU provider.
4. How the vLLM stack is constrained to dedicated tenancy, integrity checks, and no-training guarantees.
5. How audit events and inference responses flow back without exposing plaintext prompt content at the provider.
